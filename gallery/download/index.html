Every download

For Windows, macOS, and Linux.

The same FrameSeq in each, with the frameseq command beside the Studio.

Windows

64-bit

Installer.exe{{size:win-setup}} Portable.zip{{size:win-zip}}

The installer needs no administrator rights and puts FrameSeq Studio in the Start menu. The portable zip installs nothing: unzip it anywhere and run bin\frameseq.cmd.

macOS

Apple silicon and Intel

Apple silicon.dmg{{size:mac-arm64}} Intel.dmg{{size:mac-x64}}

Open the disk image and drag FrameSeq Studio to Applications. It brings its own browser for exports.

Linux

x64 and ARM64

x64.tar.gz{{size:linux-x64}} ARM64.tar.gz{{size:linux-arm64}}

Unpack it and run ./FrameSeq/install.sh. The Studio's window needs WebKitGTK 4.1, which most desktops have.

The first time you open it

The app is not signed yet.

  • Windows SmartScreen may ask before running the installer: choose More info › Run anyway. With Smart App Control on, Windows may now and then refuse it; try again a little later, or use the portable zip.
  • macOS The first time, macOS asks you to confirm: open FrameSeq Studio from Finder with Control-click › Open.
  • Linux It runs as it is. Where the Studio's window cannot open, the Studio opens in a browser's app window instead.

What is inside

Everything FrameSeq needs.

  • FrameSeq Studio, in a window of its own
  • The frameseq command, for exports and checks
  • Node.js, used only by FrameSeq
  • The Typst compiler and Tectonic for Typst and LaTeX
  • A browser for exports on macOS and Linux; Windows uses Edge

FrameSeq Studio tells you when a newer FrameSeq is out.

Prefer npm?

Start a project in your own toolchain.

With Node.js already installed, a new project comes with the Studio, a theme, and scripts for every export.

Getting started → 
$ npm create frameseq@latest my-talk
$ cd my-talk
$ npm install
$ npm run studio
