下载 FrameSeq

全部下载

Windows、macOS 和 Linux 都有。

每个版本里都是同一个 FrameSeq，Studio 旁边还有 frameseq 命令。

Windows

64 位

安装程序.exe{{size:win-setup}} 便携版.zip{{size:win-zip}}

安装程序不需要管理员权限，装好后 FrameSeq Studio 会出现在开始菜单。便携版什么都不安装：解压到任意位置，运行 bin\frameseq.cmd。

macOS

Apple 芯片和 Intel 芯片

Apple 芯片.dmg{{size:mac-arm64}} Intel 芯片.dmg{{size:mac-x64}}

打开磁盘映像，把 FrameSeq Studio 拖进“应用程序”。它自带用于导出的浏览器。

Linux

x64 和 ARM64

x64.tar.gz{{size:linux-x64}} ARM64.tar.gz{{size:linux-arm64}}

解压后运行 ./FrameSeq/install.sh。Studio 的窗口需要 WebKitGTK 4.1，大多数桌面环境都已自带。

第一次打开时

应用目前还没有签名。

FrameSeq 是免费的，而代码签名证书要花钱。每个下载文件都由 GitHub Actions 从版本标签公开构建。

  • Windows 运行安装程序前，SmartScreen 可能会询问：选择 更多信息 › 仍要运行。开启了智能应用控制时，Windows 偶尔会拒绝运行；稍后再试一次，或者改用便携版 zip。
  • macOS 第一次打开时需要确认：在访达里 按住 Control 点按 › 打开 FrameSeq Studio。
  • Linux 直接就能运行。Studio 的窗口打不开时，会改在浏览器的应用窗口里打开。
  • 核对下载的文件 每个版本都在 SHA256SUMS.txt 里列出每个文件的 SHA-256。用 PowerShell 的 Get-FileHash、macOS 的 shasum -a 256 或 Linux 的 sha256sum 算出你下载的文件的值，和它比对。

安装包里有什么

FrameSeq 需要的都在这里。

  • FrameSeq Studio，有自己的窗口
  • frameseq 命令，用来导出和检查
  • Node.js，只供 FrameSeq 使用
  • Typst 编译器和 Tectonic，用于 Typst 和 LaTeX
  • macOS 和 Linux 上用于导出的浏览器；Windows 使用 Edge

有新版本的 FrameSeq 时，FrameSeq Studio 会提醒你。

更喜欢 npm？

在你自己的工具链里新建项目。

电脑上已经有 Node.js 的话，新项目里会带上 Studio、一个主题，以及每种导出的脚本。

用代码上手 → 
$ npm create frameseq@latest my-talk
$ cd my-talk
$ npm install
$ npm run studio
