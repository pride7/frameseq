同一页，两种视图

可以隐藏代码，也可以放在旁边。

按 Ctrl+E 收起编辑器，不想看代码的人完全不用看。再次打开时，光标正停在你选中的对象上：拖动一个形状，只有它的数字会变。

  • 按住 Alt 点击任意对象，跳到对应的代码行
  • TypeScript 自动补全、悬停说明和实时报错
  • 一份纯文本文件放进 Git：能比较、能审阅、能开分支

AI 助手

说一句要怎么改，再逐条决定是否采纳。

AI 助手面板会调用你电脑上的 Claude Code 或 Codex，用你自己的账号。它修改幻灯片、检查布局、查看自己画出的效果，再把每一处修改摆出来，由你决定接受还是拒绝。

  1. 1

    用自己的话提要求

    请求会附带当前看到的幻灯片、选中的代码行和问题列表，所以你说“这一页”，它知道是哪一页。

  2. 2

    它会检查自己的成果

    通过 frameseq mcp，AI 会先运行布局检查、查看幻灯片截图，确认没问题才说完成。

  3. 3

    留不留由你决定

    编辑器把每处修改和原来的内容对照显示，逐条接受或拒绝。按 Ctrl+Z 可以全部撤回。

想用自己的 AI 工具？

Claude Code、Codex 和 Cursor 可以连接 frameseq mcp，读取大纲、检查布局、查看幻灯片。任何模型都能从 llms.txt 学会这门语言。

放映

双屏放映，看着备注讲，用手机翻页。

按 F5，幻灯片铺满整个屏幕。接上投影仪时，幻灯片显示在投影上，你的笔记本上则是演讲者视图：备注、下一页和计时器一目了然。

全屏放映

F5 从头开始，Shift+F5 从当前页开始。点击或方向键逐步展示内容，放映结束时黑屏。

背后的代码

一份从上往下读的文件。

每一页只是几行 TypeScript，没有嵌套，也没有标记语言。代码的顺序就是阅读的顺序，所以 diff 一眼就能看出改了什么，AI 写起来也不会迷路。

talk.slides.ts 
slide("每个版本都更快").split("38:62")
  .notes("中位加载时间，在中端手机、4G 网络下测得。");
text("一年里，首块瓦片的中位加载时间降低了三分之二。").lead();
bullets(
  "矢量瓦片取代了图片",
  "每个边缘节点都有缓存",
  "字体随应用一起分发",
);

right();
chart("bar", { "1.0": 840, "1.4": 610, "1.8": 430, "2.0": 280 })
  .unit(" ms")
  .colors("#0d9488");

为真实的演讲而生

流程图、公式、图表和海报。

每一样都是一条带合理默认值的命令，所以 AI 能画得好；导出到 PowerPoint 之后，每一样也都还能编辑。

流程图

形状和连接线，导出后依然可编辑

27 种形状，配色会根据主题自动调整；连接线可以直角转弯，自动绕开挡路的对象。导出到 PowerPoint 时，用的是它自带的预设形状。

排版

LaTeX 公式和 Typst

用熟悉的 LaTeX 写行内或独立公式；需要更复杂的排版时，可以嵌入 Typst 或 LaTeX 表格。

图表和表格

到了 PowerPoint 还能改的数据

柱状图、折线图、饼图、环形图和三线表，都直接由文件里的数字画出。导出后就是 PowerPoint 原生的图表和表格。

海报

用同一门语言做 A0 海报

标题横幅、分栏内容块，字号按纸张尺寸设定。导出的 PDF 就是纸张的真实尺寸。

一份文件，四种格式

网页上放映，PDF 拿去提交，PowerPoint 交给同事。

形状、图表和表格导出到 PowerPoint 后都是原生对象，同事可以直接修改；每种导出都可以只选其中几页。

PPTX

PowerPoint

可编辑的文本框、预设形状、图表和表格，母版内容画在每一页后面。

frameseq pptx talk.slides.ts
PDF

PDF

像素级还原，海报按纸张尺寸输出，适合投稿和打印。

frameseq pdf talk.slides.ts
HTML

网页

可交互的幻灯片，带演讲者视图，放到任何静态网站上，或者直接分享链接。

frameseq build talk.slides.ts
TYP

Typst

可以继续排版的 Typst 源码，形状、表格和连接线都是原生 Typst。

frameseq typst talk.slides.ts
