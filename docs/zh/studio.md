# FrameSeq Studio

FrameSeq Studio 把写一场讲演的整个循环放进一个窗口：缩略图形式的全部幻灯片、带 TypeScript 支持的 `.slides.ts` 源码编辑器、实时预览，以及一份列出这份演示所有问题的清单。除了 FrameSeq 包本身，它什么都不需要：不用另装编辑器、扩展或单独的程序。

```bash
frameseq studio talk.slides.ts
```

这条命令会启动开发服务器并打开 Studio。如果装了 Chrome、Edge、Chromium 或 Brave，Studio 会以一个独立的应用窗口打开，没有标签页也没有地址栏；否则在默认浏览器里打开。用 `npm create frameseq` 生成的项目可以用 `npm run studio` 做同样的事。

源码仍然是这场讲演唯一的描述。Studio 里的每个操作，无论是打字、在预览里拖拽，还是在左侧栏里调整页面顺序，最终都是对 `talk.slides.ts` 的一次编辑，编辑器自己的撤销就能把它撤回。

## 窗口布局

| 区域 | 内容 |
| --- | --- |
| **Slides**（左） | 每一页幻灯片，由和预览相同的运行时渲染，每次保存后都会更新。 |
| **编辑器**（中） | 幻灯片文档，带 TypeScript 补全、错误提示、悬停文档和参数提示。 |
| **Preview**（右） | 交互式预览，保留它原有的翻页、缩放和布局编辑控件。 |
| **Problems**（下） | TypeScript 错误、布局检查结果、构建错误，以及演示运行时抛出的错误。 |

拖动分隔条可以调整各区域大小，双击分隔条恢复默认值。`Ctrl+B`（macOS 上为 `⌘B`）隐藏左侧幻灯片栏，`Ctrl+J` 隐藏底部面板。这些尺寸会被浏览器记住。

**Auto-save** 旁边的主题按钮可以在跟随系统（◐）、浅色（☀）和深色（☾）之间切换。幻灯片本身仍然使用演示文稿自己的主题。

## 编辑与保存

顶栏的 **Auto-save** 默认开启：停止打字片刻后 Studio 就会保存，预览随即按保存后的文件重绘。自动保存只写入能够解析的文本。一行还没写完、或者括号不配对时，保存状态显示 **Not saved: syntax error**，预览继续显示上一个能运行的版本，而不是在每次按键之间闪出构建错误。`Ctrl+S` 则总会保存，不管文本是什么样子。

关掉自动保存后，只有按 `Ctrl+S` 才保存；预览显示的是最后一次保存的文件。

编辑器像普通编辑器一样从最近的 `tsconfig.json` 读取项目，所以它的补全和错误与 VS Code、`tsc` 一致。开始输入一条命令，或在命令后输入 `.`，就会出现补全；把鼠标停在名字上可以看到文档；打开一个调用的括号会显示它的参数。不在任何 TypeScript 项目里的演示文件也能得到 FrameSeq 的全局函数类型。

每个 `slide()` 调用开始的那一行旁边都有页码标记，点击它就会显示那一页。源码旁的一条竖带标出预览当前正在显示的那一页。

## 编辑器与预览互相跟随

打开 **Follow cursor** 后，移动光标会显示光标所在的那一页，并框出这一行写出的对象。光标停留在同一页里时，预览会保留当前的逐步显示进度。

预览自带的源码链接和在 VS Code 里一样：

- 在预览里按住 **Alt 点击**对象，光标会移到画出它的那条命令上。
- 按 **E** 打开布局编辑，然后**拖动**用 `position({ x, y })` 定位的对象，或调整写明了 `width()`、`height()` 的对象的大小。只有数字会改变，而且是通过编辑器改的，所以 `Ctrl+Z` 能把对象放回原处。焦点在预览里时这些快捷键同样有效：`Ctrl+Z` 和 `Ctrl+Y` 在编辑器里撤销和重做，`Ctrl+S` 保存。
- 拖动处在文档流里的对象，可以改变它在相邻对象之间的位置；它的源码行会连同注释一起移动。
- 按住 `Ctrl` 点选几个前后相连写下的对象，再选 **Bind region**，就会把它们的源码行包进一个命名的 `at("…").column()` 区域，之后可以整体定位或锚定。

拖拽可以改写哪些数字，规则见 [Visual Studio Code 扩展](vscode.md)。

## 调整页面

左侧幻灯片栏按“生成页面的语句”来编辑文档。一页的源码从它的 `slide()` 语句开始（连同紧贴在上方的注释），到下一页的源码开始处为止，所以它的内容和后面的空行会跟着它一起走。

- **点击**缩略图：显示这一页，并把编辑器移到生成它的代码处。
- 上下**拖动**缩略图：移动这一页。
- **右键**可以选择 **New slide after**、**Duplicate**、**Move up**、**Move down**、**Go to source**、**Present from here** 和 **Delete**。选中缩略图后按 `Delete` 也能删除。
- 幻灯片栏上方的 **+**：在预览当前页之后新增一页，并选中标题方便直接输入。

这些操作在编辑器的历史里都只占一步。

### 用代码生成的页面

一个循环、或者一次辅助函数调用，会用一条语句生成好几页：

```ts
for (const topic of ["Alpha", "Beta", "Gamma"]) {
  slide(topic);
  text(`About ${topic}`);
}

section("Results"); // 一个会写出两页的辅助函数
```

这些页面没有哪一段源码单独属于其中某一页，所以它们作为生成它们的那条语句，一起移动、复制和删除。幻灯片栏会用竖线把这样的页面括在一起，编辑器给这条语句标上它生成的所有页码（如 `2–4`），右键菜单会说明一个操作会影响几页，拖动时也只能放在两组之间。循环前后的普通页面仍然可以逐页移动，声明在两页之间的辅助函数也会留在原处。

点击循环生成的页面，光标会落在循环里的 `slide()` 调用上；点击辅助函数生成的页面，光标会落在调用这个函数的那一行。由导入的模块生成、不在幻灯片文档里的页面，可以显示，但不能在这里调整。

## 问题列表

Problems 面板汇集四类结果，随着编辑不断刷新：

- **TypeScript**：编辑器里画波浪线的那些错误。
- **Layout**：[`frameseq check`](layout-checks.md) 的规则，每次保存后都对实时演示测量一遍，而不是等你手动运行：画布溢出、文字被裁切、字号过小、空白页和空区域、相似的区域名，以及不起作用的修饰符。
- **Build**：服务器编译演示时报告的错误，比如无法编译的 Typst 或 LaTeX 片段。
- **Preview**：演示运行时抛出的错误。修好之前，预览会一直显示上一个能运行的版本。

点击一条结果就会跳过去：TypeScript 错误会选中对应文本，布局问题会显示所在的那一页、框出对象，并把光标放到写出它的那一行。

## 别处做的修改

Studio 会监视幻灯片文档。当它在磁盘上被修改（比如由编程代理或另一个编辑器写入），而 Studio 里没有未保存的编辑时，新文本会立刻载入，而且 `Ctrl+Z` 仍然可以撤回这次载入。如果你有未保存的编辑，顶部会出现提示条，让你选择保留哪个版本：**Use the file on disk** 或 **Keep my version**。不经过这个选择，任何内容都不会被覆盖。

## 演示与导出

**Present**（`F5`）会在一个独立窗口里，从当前页打开[演讲者视图](presenter.md)。**Export** 运行与 CLI 相同的导出，并写到相同的位置：

| 导出 | 写入 |
| --- | --- |
| PDF | `output/pdf/<name>.pdf` |
| 可编辑的 PowerPoint | `output/pptx/<name>.pptx` |
| 每页一张图片的 PowerPoint | `output/pptx/<name>.pptx` |
| 单个 HTML 文件 | `dist/index.html` |
| HTML 站点 | `dist/` |
| Typst 源码 | `output/typst/<name>.typ` |

这些路径相对于启动 Studio 时所在的目录。导出开始前会先保存文档。导出完成后，提示里会提供 **Download** 和 **Show in folder**；完整日志在 **Output** 标签页里。

## 键盘快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+Z`、`Ctrl+Y` | 撤销与重做，在预览和幻灯片栏里同样有效 |
| `Ctrl+Space` | 显示补全 |
| `Ctrl+F` | 在编辑器里查找和替换 |
| `Ctrl+PageDown`、`Ctrl+PageUp` | 下一页、上一页 |
| `F5` | 从当前页开始演示 |
| `Ctrl+B` | 显示或隐藏幻灯片栏 |
| `Ctrl+J` | 显示或隐藏底部面板 |

在 macOS 上，用 `⌘` 代替 `Ctrl`。

## 网络访问

Studio 会写入整份文档，而普通预览从不这样做：在 `frameseq dev` 里拖拽只能改写数字。因此 Studio 的接口只存在于由 `frameseq studio` 启动的服务器上，只响应运行它的这台电脑，并拒绝任何其他网页发来的请求。只有在必须从这台机器之外访问 Studio 时（例如在容器或浏览器 IDE 里），才加上 `--host`：

```bash
frameseq studio talk.slides.ts --host
```

这样一来，任何能访问这个地址的人都可以编辑这份演示。用 `--no-open` 只启动服务器而不打开窗口，用 `--tab` 在浏览器标签页而不是应用窗口里打开。
